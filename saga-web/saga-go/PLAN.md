## 2. 반드시 지킬 것

루트 `CLAUDE.md`(세이브 키 `deungyong-go/save/<프로필>` 불변 · 펫 id 불변 · 이름 정책 · IV/CP 금지 · 다섯 벌 복사 · 원작 에셋 금지 · 헤드리스 스크린샷 금지)는 링크만. 아래는 **이 판 고유**.

### 2.1 개발 원칙(토큰·범위)
- 구조부터 본다: `index.html` 스크립트 순서 → `game.js`(boot) → 렌더 핵심(`world.js`·`world3d.js`) → UI(`ui.js`) → `assets/`. 필요한 파일만 읽고, 한 번 본 구조는 재분석하지 않는다.
- **금지**: 기존 파일 전체 삭제 · 시스템 전체 재작성 · 필요 없는 리팩토링 · 컴포넌트 구조 일괄 변경 · 라이브러리 대규모 추가 · CSS 통째 교체 · 프레임워크 교체.
- **허용**: 함수 추가 · 기존 함수 수정 · 컴포넌트 추가 · 로더 추가 · 데이터 구조 확장.
- 작업은 단계별. 단계마다 `MODIFY`/`CREATE` 파일을 구분해 적고, 끝나면 변경 파일·내용·테스트 결과·남은 문제만 보고한다.
- 기존 UI(지도·2.5D·파티·사명·행낭·천거·도감·사관·기록·서당)는 유지한다. 새 시스템이 기존 기능을 깨면 안 된다.
- 단계마다 확인: JS 구문 · import · asset 경로 · 404 · GLB 로딩 · 모바일 Safari/Chrome · orientation · resize · touch · memory leak. 회귀 확인 대상: 게임 시작·이동·지도·파티·사명·행낭·도감·기록·기존 버튼·UI·터치.

### 2.2 에셋 원칙("코드로 그리지 말고 에셋으로", 다섯 판 공통 지시)
- 코드가 도형·그림을 조립해 만들던 것은 **전부 실제 에셋**으로 간다 — 3D 소품·건물·인물뿐 아니라 도감 일러스트·인물 초상·UI 그림까지. 스크립트에 남는 것은 이벤트와 기능(판정·규칙·상태)뿐.
- 사용자는 **품질을 먼저** 골랐다. 받을 수 있는 CC0 에셋이 이 판의 결(한옥·갓·도포)과 달라도 "둘 다 얹는다(품질 우선)". "결이 안 맞아서" 는 안 하는 이유가 되지 못한다.
- **되돌림 길은 지우지 말고 손잡이로 남긴다**(`file://` 단독판 · LOW 등급 · 오프라인은 옛 그림으로 돌아간다).
- 에셋을 못 구하면 "안 한다" 가 아니라 "이래서 막혔고 대신 이것을 할 수 있다" 로 보고한다. 이 망은 GitHub(`raw.githubusercontent.com`·`api.github.com`)만 열려 있다.
- 출처·라이선스는 `assets/ASSET_LICENSES.md`, 기술값(폴리곤·텍스처 크기)은 `assets/ASSET_CATALOG.md` — 둘 다 같이 고친다. CC0 우선, 재배포 불가는 받지 않는다, CC-BY 는 표시 문구를 옮긴다.
- 품질 방향: stylized · 적당한 폴리곤 · 모바일 친화 · 일관된 스타일·광원·스케일. 서로 다른 스타일을 섞지 않는다(→ §6 아트 바이블과 충돌하는 실사 인물은 §10-Q1).
- 로더는 공통 `asset3d`(AssetManager 역할: load/clone/preload/clearUnused). 같은 GLB 를 두 번 받지 않고 clone/`InstancedMesh` 로 세운다.

### 2.3 월드·콘텐츠 규칙
- 목적지 사슬: 시작 마을 → 논밭 → 숲 → 계곡 → 강 → 산길 → 폐허 → 도적 소굴 → 성곽 → 숨겨진 지역. 랜드마크 5~10(성·산 정상·폭포·거대 나무·옛 사당·붉은 다리·폐허 성문·거대 바위·호수·탑).
- 평면 지형 금지(평지·언덕·경사·계곡·산·강·절벽·숲·농지·마을). 격자 배치 금지 — scale·rotation·position·색 variation·군집.
- 밀도 목표 비율(기준값, 고정 아님): 자연물 30 · 건축 20 · NPC/동물 15 · 수집/상호작용 15 · 전투 10 · 랜덤 이벤트 10.
- 지역별 생태계·분위기: 마을(따뜻·밝음) · 숲(녹색·안개·늑대·멧돼지·도적) · 산(바위·절벽·강풍·산적·야수·정예병) · 폐허(어둡고 황량·망령·도적·보스) · 성(웅장). 밤·희귀 지역엔 특수/엘리트 적.
- 시간(아침·낮·해질녘·밤; 밤엔 횃불·조명·NPC 변화·야행성·특별 이벤트)·날씨(맑음·흐림·비·안개·눈)·계절은 **시각의 순수 함수**(어느 기기·언제 물어도 같은 답, 진단이 값으로 붙든다).
- NPC 는 서 있기만 하면 안 된다(걷기·대화·앉기·작업·바라보기). 마을엔 집·시장·상점·여관·대장간·창고·우물·농장·NPC·동물·길·장식.
- 발견은 남는다(발견 연출 + 도감). 탐험 보상: 지역 발견→경험치 · 보물→아이템 · NPC→퀘스트 · 희귀 장소→도감 · 숨은 지역→특별 보상. 숨은 자리는 가 보기 전까지 지도에 안 뜬다.
- **절대 넣지 말 것**: 의미 없는 거대한 맵 · 빈 평원 · 동일 나무 반복 · 모든 건물 같은 모델 · 과도한 파티클 · 모바일에서 무거운 후처리 · 무작정 고폴리 · 과도한 애니 · UI 만 바꾸고 월드는 그대로.

### 2.4 모바일·성능 규칙
- 우선순위: **1 안정성 · 2 FPS · 3 로딩 · 4 그래픽**. 저사양 30FPS 안정, 고사양 60FPS 목표.
- 세로(상단 최소 HUD·하단 조작·미니맵·플레이어 중심)·가로(넓은 시야·확장 미니맵·파티·퀘스트) 둘 다. `orientationchange`+`resize` 대응. 고정 px 최소화(clamp·vw·vh·safe-area-inset·flex·grid). 노치·홈 인디케이터 고려.
- 터치: 이동 조이스틱 · 카메라 드래그 · 핀치 줌 · 탭 선택 · 탭 상호작용. 데스크톱 WASD·마우스·휠 유지.
- 카메라: 추적·부드러운 follow·줌·회전·경계·지형 충돌·터치.
- 성능: draw call(인스턴싱·geometry/material 공유·atlas·model cache) · LOD 3단(고품질/중간/빌보드) · 품질 HIGH/MEDIUM/LOW 자동(모바일 초기 MEDIUM) · 그림자는 중요 오브젝트만 · 4K 텍스처 금지 · 필수 에셋(플레이어·기본 맵·시작 마을) 먼저 로딩 후 지역별 lazy · 스트리밍 반경(ACTIVE < VISIBLE < UNLOAD) · 캐시 정책으로 재로딩 억제.
- **3D 값을 고쳤으면 `sw.js` 의 `VERSION` 을 올린다**(안 올리면 폰이 옛 캐시를 본다).
- `core.hash2` 는 이 판만 옛 식(0~0.5 반환)이다. 지형 문턱값이 그 범위에 맞춰져 있어 그대로 둔다.
