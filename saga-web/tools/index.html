saga 게임 제작 도구

로컬 전용. 게임 서버가 아니다 — 커밋·푸시는 하지 않는다. 두 편집기 위 줄의 ▶ 실행(F5)은 게임을 편집기 안에서 띄운다(연습용 세이브).

도감(data.js HEROES·PETS·BIOS)을 다섯 판에 함께 반영, 판별 data-*.js 표 편집, 3D 자산 재할당·업로드, 실명 가드.

맵 편집기 확인 중…

판별 지도(글자 격자·좌표 표)를 칠하고 옮긴다. 3D 배치 — 사가고 땅에 소품을 3D 화면에서 놓고 옮기고 돌리고 키운다(기즈모). 검사는 그 판 게임 코드 그대로.

새 판 뼈대 생성기

서버가 아니라 명령줄 도구다 — 바로 도는 최소 판을 하나 만든다.

node saga-web/tools/new-game/new-game.mjs --folder saga-xxx --title .. --port .. [--dry]
