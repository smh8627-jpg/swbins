# saga-web 맵 편집기

판 `js/land.js` 의 "글자 그림" 지도(`map`)와 명소(`places`)를 브라우저에서 칠하고 옮기는 로컬 전용 도구.
지금은 사가고 `hebei`(하북의 작은 마을, 21×21칸·한 칸 48m)가 대상이다 — 다른 판에 `js/land.js` 가 생기면 저절로 목록에 뜬다.

```
run-map-editor.bat        → http://127.0.0.1:8800/   (끄기: 창 닫기 또는 Ctrl+C)
```

- **도구**: 칠하기(끌기) · 채우기 · 스포이트 · 명소 옮기기 · 오른쪽/아래로 열·줄 늘리고 줄이기 · 되돌리기(Ctrl+Z).
  왼쪽·위로는 안 늘린다(격자 원점 `ox/oy` 와 명소 좌표가 한꺼번에 밀린다). 흰 테두리 칸 = 격자 (0,0), 게임 시작 자리.
- **범례**는 그 땅의 `legend` 를 그대로 쓴다(새 글자·지형은 `land.js` 에서 코드로 먼저 정의).
- **검사는 게임 코드 그대로**: 고친 `land.js` 를 vm 에서 실행해 그 판의 `validate()`·`roadIslands()`·`tally()` 를 부른다 —
  게임 `_test.html` 땅 진단과 규칙이 어긋나지 않는다. 칠할 때마다 오른쪽에 바로 뜬다.
- **저장**은 그 땅 객체의 `map: [...]`·`places: [...]` 구간만 바꿔 쓴다(주석·범례·다른 코드 그대로, 안 바꾸고 저장하면 바이트까지 같다).
  막는 것: 그새 파일이 바뀜(md5) · 파일 구문 오류 · `validate()` 오류 · 명소 이름 실명(`../content-editor/realname.js`).
  길이 끊긴 것(`roadIslands() ≠ 1`)은 막지 않고 경고만 한다. 저장하면 그 판 `sw.js` VERSION 을 한 번 올린다.
- 게임 `_test.html` 땅 진단은 지형 갈래 개수·숨은 곳 넷 같은 **내용 조건**도 본다 — 편집기는 형식만 막으니, 크게 고쳤으면 진단을 한 번 돌린다.
- git 은 건드리지 않는다.
