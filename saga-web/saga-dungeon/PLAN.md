## 1. 정체성

- **한 줄**: 역사 인물 105명을 부대로 이끌고, 마을 104개가 이어진 들판과 여섯 결의 던전을 도는 **탑다운 3D 액션 RPG**. 디아블로 2의 규칙(소켓·룬워드·정예 접사·난도·역참·결사·행상·투전·연단·내구·감정·창고·투장·고유)을 거의 다 옮겨 왔고, 디아블로 4의 오픈월드(이어진 마을·길·필드 이벤트·수집품)를 얹었다.
- **원작 오마주**: 디아블로 2·4. 표시 이름은 전부 가명(루트 CLAUDE.md 이름 정책). 원작 에셋 없음.
- **인물이 되는 것 — 서명 무예(署名武藝)**: 다섯 판 공통 인물 105명이 이 판에서는 **인물마다 하나씩 다른 서명 무예**(`js/data-hero-skill.js` `SIG`, 105/105 완료)로 존재한다. 직업(무기가 정한다) 트리는 공유, 서명 무예는 인물 고유. 부대(최대 5)의 2번째 인물은 동행(同行)으로 곁에서 싸운다.
- **이 판만의 차별점**: ① 부대 전투력이 곧 몸(`hero.partyPower`) — 인물을 키우면 더 깊이 내려간다. ② 인물은 던전에서 온다(출사표 3명 + 보스층 3층마다 1명 합류). ③ 은사(恩賜)는 회차 한정 — 층을 내려갈 때 셋 중 하나. ④ **퓨전 선행 판**(2026-09-10 창작 방향, `SAGA-HANDOFF.md` "창작 방향"): 과거×현대×미래 캐릭터·건물·무기를 다섯 판 중 이 판에서 먼저 실험한다. 첫 반영이 원소 전자(電磁, `emp`)와 여덟째 무예 갈래.
- **플레이어 판타지**: "내가 고른 인물들이 내 손끝에서 하나씩 다른 기술을 뽐내며, 걷다 보면 뭔가 나오는 넓은 세계를 내려간다." 지금은 이 판타지의 재료(인물·무예·세계)는 다 있는데 **루프와 손맛이 재료를 못 살린다**(§4).

## 2. 반드시 지킬 것 (이 판 고유 — 루트 CLAUDE.md 공통 규칙은 링크만)

### 2.1 구조 불변식
- **판정(`dungeon.js`)과 화면(`dungeon-view.js` 2D·`dungeon3d.js` 3D)은 갈라져 있다.** 3D 는 화면 계층으로만 얹는다. 판정 파일에 three.js 를 부르지 않는다. WebGL 이 없으면 조용히 2D 로 돈다.
- **`strike()` 가 모든 피해의 단일 통로**다(평타·무예·강공격·투장 무예·서명 무예·동행·분신). 새 피해 경로를 만들지 않는다 — 어그로 각성·hitstop·콤보가 전부 여기 걸려 있다.
- **모양(shape)은 열 가지뿐**: swing·nova·bolt·dash·buff·heal·curse·summon·chain·passive(`applyShapeSkill`). 무예를 늘릴 때 모양을 늘리지 않는다 — 모양 하나마다 `dungeon.js` 에 동작을 새로 써야 한다. curse·heal·buff·summon 은 `el` 을 읽지 않는다(붙이지 말 것).
- **던전 내부는 방 단위 로그라이크로 유지**(`run.room` 단일 객체, `seedOf(floor,roomIdx,theme)`, `isBoss = roomIdx>=roomTotal-1`). 방 개념을 없애는 A안은 반려됐다 — 방-방 전환은 문별 통로(동쪽 벽 `doorCorridorUnits()`)로 위장 전환한다. 자동 순회(`auto.js`)는 통로를 건너뛰고 `goRoom()` 직접 호출.
- **마을↔필드↔마을은 진짜 이어진 하나의 세계 좌표계**(옛 §28-8 A안). `ctx.anchor`(마을 로컬 원점의 세계 좌표)·`ctx.noRoom`(열린 들판) 이 없으면 옛 동작과 100% 같아야 한다(던전 방은 이 필드를 안 넘긴다). 마을 간 순간이동은 없다 — 되돌리지 말 것. `travel()`·통로 클램프 표(`corridorsFor` 등)는 은퇴했다.
- **그림·판정·자동지도가 같은 산식을 본다**: `field3d.kindOf/chunkAt/heightAt` 을 `dungeon3d.buildField`(그림)·`dungeon.fieldBlockedAt`(충돌)·`town.worldKindAt/worldPropsAt`(지도) **세 곳이 똑같이** 부른다. 한 곳만 고치면 "보이는 건 물인데 밟히는 건 바위" 가 난다(세 번 밟은 함정).
- `town.js` `exits` 데이터(갈대나루 3·자작재 2·소금벌 2)는 자가진단이 지킨다. 길은 `exits` 와 별개인 `ROAD_SEGMENTS` 선분이다.
- `run` 은 세이브에 안 남는다(회차는 앱을 끄면 사라진다). `core.save.dungeon` 은 메타(best·runs·kills·clears·mode)만.

### 2.3 작업 규칙(이 판에서 실제로 밟아 정한 것)
- 파일을 늘리거나 고쳤으면 **`sw.js` VERSION 을 같이 올린다**. 새 js 파일은 `sw.js` `SHELL` 목록·`index.html`·`_admin.html`·`_demo.html` 네 곳에 다 넣는다(`data-hero-skill.js`·`starter.js` 가 빠졌던 적 있다).
- **RNG 순번 함정**: 밑감·적·데이터 표를 늘리면 `Math.random()` 소비 순서가 밀려 무관한 자가진단이 깨진다. 새 판정에 무작위가 필요하면 `core.hash2(고정 입력)` 순수 해시로. 자가진단 항목은 **파일 맨 끝에** 추가하고 앞선 테스트 상태(`room.enemies=[]`·`room.decor=[]`·`uniq:false`)에 기대지 않게 격리한다.
- `_test.html` 은 3D 렌더를 켜지 않는다(`DG_NO_DRAW`). 화면 층(`dungeon3d.js`)이 세계 좌표를 다루는 코드는 진단 통과만으로 안심하지 않는다 — 실기 확인 항목으로 §7 에 적는다.
- 에셋: CC0 만, 출처는 `assets/ASSET_LICENSES.md`. **Quaternius 최신 팩 상당수가 QAL(재배포 금지)** — 이름만 보고 받지 않고 팩 페이지에서 낱개 확인. itch.io 는 curl 로 못 받는다 → OGA 미러·poly.pizza 직접 URL. `npm install fbx2gltf` 가 이 환경에서 실제로 돈다. 승인 제외 목록(alien·alpaking·armabee·bunny·cat·chicken·fish·pigeon류 — 이 판 결에 안 맞음, 2026-09-09)은 되살리지 않는다.
- "코드로 그리지 말고 에셋으로"(사용자 지시 2026-08-28, 다섯 판 공통): 도형을 조립해 그리던 것(3D 소품·건물·인물·초상·카드·아이콘)은 실제 에셋으로 갈아 끼운다. 되돌림 길(옛 그림)은 손잡이로 남긴다. 결이 안 맞는다는 이유로 안 하지 않는다(품질 우선, 사용자 확인). 못 구하면 "막혔고 대신 이것" 으로 보고한다.
- 3인칭 카메라·등신 비례 토글·그림 양식 토글은 지웠다(`diablo` 하나로 고정). 되살리지 않는다.
- 헤드리스 크롬은 PID 로만 죽인다(`taskkill //F //PID`). 이미지 이름으로 죽이지 않는다(사용자 브라우저를 끊은 적 있다).

### 5.1 축복(祝福) 3택 — 은사를 회차 빌드로 재해석
- **참고**: 하데스 축복 조합, PoE 스킬+서포트, 슬레이 더 스파이어 유물. **표준**: D·G(부분 A).
- **왜**: 은사 3택이 이미 층마다 걸리는데 표(`BOONS`)가 스탯 % 라 "뭘 골라도 같다". 무예 120·서명 무예 105 라는 재료를 **회차 안에서 조합**하게 만들면 갈래를 더 안 늘려도 선택이 생긴다.
- **메커니즘**: `descend()` 의 `rollBoonChoice()` 를 세 축에서 하나씩 뽑게 바꾼다 — ① **무예 축**(걸어 둔 무예 4칸 중 하나를 강화: 모양별 고유 효과 — swing 범위+25%, bolt 관통 1, nova 링 2회, dash 무적 +0.1s, chain hops +2, summon 수 +1, curse 지속 +40%, heal 즉시 +30%, buff 지속 +50%) ② **인물 축**(서명 무예 강화: 쿨다운 -25% / 위력 +40% / 발동 시 부대 전원 흔들림·플래시, 또는 부대 3~5번째 인물의 "그림자 서명" — 그 인물 서명 무예를 20% 확률로 평타에 얹음) ③ **세계 축**(원소 시너지 — 화+뇌 "폭발" 처치 시 반경 80 화상 / 빙+기 "결빙" 슬로우 중 피해 +30% / 독+전자 "부식" 저항 -20% / 물리+화 "작열" 콤보 6 이상에서 화상 등 7원소 조합표 12개). 희귀도 3단(일반 60%·희귀 30%·전설 10%), 같은 축 중복 금지, **거절** 시 금 30×층. 회차 최대 스택 8(3층마다 1 + 사당방 보너스). 축복은 회차 한정(기존 은사 규칙 그대로), 처음 본 축복은 도감 "은사첩" 에 등록(메타 진행 — F 표준의 "죽어도 남는 것").
- **수치**: 강화 배율은 위 값 고정, 전설 축복은 두 효과 합성. 원소 시너지 피해는 `strike()` 안에서 `run.boons` 를 읽어 한 번만 계산(새 통로 없음). 밸런스 목표: 8스택 회차의 DPS 가 0스택의 2.2배 이내(어드민 시뮬레이터로 잰다).
- **UI·조작**: 기존 은사 카드 3장 UI 재사용, 카드 위 축 아이콘(무예🗡·인물👤·세계🌐)과 희귀도 테두리색(등급색 TIERS 재사용). 거절 버튼 추가. HUD 오른쪽 위 축복 아이콘 띠(최대 8).
- **세이브**: `run.boons` 는 회차(저장 안 함). 메타 `save.dex.boons = {key:true}` 신설 — `freshSave()` 에 추가, `mergeDeep` 이 옛 세이브에 채운다(마이그레이션 코드 없음). `DEX_COMPLETE` 에 `boons` 갈래, 완성 보상은 기존 파이프라인.
- **진단 문안**: "축복 — 세 카드가 서로 다른 축이다(100회)" · "축복 — 거절하면 금이 층×30 만큼 든다" · "축복 — 화+뇌 시너지가 처치 시 반경 80 화상을 건다" · "축복 — 처음 본 축복은 은사첩에 남고 회차가 끝나도 지워지지 않는다". 전부 `core.hash2` 로 굴려 씨앗 무관.
- **범위**: `data-dungeon.js`(BOONS→3축 표), `dungeon.js`(rollBoonChoice·strike 시너지·applyShapeSkill 강화값), `ui.js`(카드·HUD 띠·도감), `core.js`(dex.boons). **우선순위 1**. 충돌: 없음 — 은사 회차 한정 규칙·strike 단일 통로·모양 10 유지. 무예 갈래는 더 늘리지 않는다(사용자 "그냥 모방" 정정).

### 5.2 유품(遺品) — 죽음 비용과 회수, 죽어도 남는 것
- **참고**: 다크소울 소울 회수, 하데스(죽음→서사), 로그라이트 메타 진행. **표준**: F·B.
- **왜**: 지금은 죽으면 노획물 전부 소멸 + 아무 안내 없음. 긴장은 없고 허탈만 있다. 비용을 **회수 가능하게** 만들면 "다시 내려갈 이유" 가 생기고, "남는 것" 을 카드로 보여 주면 죽음이 진행이 된다.
- **메커니즘**: 사망 시 노획물(금·장비·재료)을 **유품**으로 그 층에 남긴다. 다음 회차에 그 층에 도달하면 유품 표식(기존 `MARKS` 결, 비석 GLB 재사용)이 서고 밟으면 회수 — 금 100%, 장비는 3점까지 선택(나머지 소멸). 회수 전에 다시 죽으면 옛 유품 소멸(1개만 유지). 사망 화면 = **세션 카드**(5.6 과 같은 카드): 남은 것(인물 경험·도감·공적·은사첩)·잃은 것(유품으로 남김)·다음 할 것 1개("N층 유품 회수"). 결사 모드는 유품 없음(원작 하드코어 그대로).
- **수치**: 유품 유지 1개, 장비 회수 3점, 회수 시 금 100%. 목표판(5.6) "지금" 줄이 유품 회수를 최우선으로 보여 준다. 사망→재도전 조작 3회 이하(카드 닫기→본영→굴혈).
- **UI·조작**: 사망 카드 1장(5초 자동 닫힘 아님 — 사용자가 닫는다, 단 조작 1회). 층 진입 시 "유품이 이 층에 있다" 토스트, 표식에 💀 이름표.
- **세이브**: `save.dungeon.grave = null | {floor, gold, items:[…], at}` 신설(`freshSave`, mergeDeep). 장비 객체는 `item.js` 의 직렬화 그대로(가방과 같은 모양).
- **진단 문안**: "유품 — 죽으면 노획물이 그 층 유품으로 남고 가방엔 안 들어온다" · "유품 — 그 층에 다시 닿으면 표식이 서고 밟으면 금 100%·장비 3점까지 돌아온다" · "유품 — 회수 전에 다시 죽으면 옛 유품은 사라지고 새 것만 남는다" · "유품 — 결사에서는 유품이 안 생긴다".
- **범위**: `dungeon.js`(die 경로·buildFloor 표식), `ui.js`(사망 카드), `core.js`. **우선순위 2**. 충돌: 없음. `run` 비저장 규칙 유지(유품은 메타).

### 5.3 부적(符籍) 던전 — 나이트메어 티어와 변형자
- **참고**: 디아블로 4 나이트메어 던전, PoE 맵 변형자. **표준**: F·G·H.
- **왜**: 난도(normal/험 …)는 최고 층으로 열리는 계단 하나라 30층 넘으면 할 것이 없다. 던전 자체를 소모품으로 만들면 반복에 이유와 변화가 생긴다.

HP 66%·33% 에서 패턴 단계 전환. 저스트 회피(공격 0.15s 전 회피 성공) 시 hitstop 0.2s + 콤보 +3. 참가 보상: 전설 확률 ×3, 부적(5.3) 1, 도감 "토벌첩" 등록.

### 5.5 난입(亂入) — 15분 생존 파도

## 7. 버그·안정화 (Phase 0 에서 닫을 목록)

### 7.1 원인 미확정·방어만 건 것
1. **"이동할 때마다 갈색 화면"** — `render()` rk 재구성·`town.build()` 실패를 try/catch 로 감쌌고 부팅은 배너로 잡는다. 안개 제거 뒤 제보가 멎었지만 근본 원인은 모른다. 재발 시 콘솔 `[loop] 프레임 실패`·`[던전 3D] 방/들판을 다시 짓다가 실패`·`[마을] build() 실패` 중 무엇이 찍히는지로 가른다. **오류 링버퍼(SAGA-DESIGN §8-2)를 `_admin.html` 에 넣어 제보가 스택으로 오게 한다.**

3. **가림 페이드(InstancedMesh)** — 진짜 페이드가 아니라 0.001 배 숨김. 처방: `instanceColor` 알파 대신 커스텀 셰이더 `aFade` 속성(Phase 6 그래픽에서).
4. **QRPG_SEEDS 표 안전성** — `mpfb_female` 이 헤드리스를 죽인 것이 레시피 탓인지 환경 탓인지 미확정. 실기 확인 항목.

## 10. 열린 질문(사용자 결정)

- **Q1 인물 30 추가 방식**: `data.js`(다섯 벌 공통, md5 일치 조건) 에 바로 넣어 다섯 판 동시 확장 vs 이 판 전용 `data-hero-ext.js` 로 먼저 실험(권장). 후자면 다른 네 판 도감에는 안 나온다.
- **Q2 낮밤·날씨**: 이 판엔 없다. 월드 보스(5.4)는 `Date` 슬롯만 쓰므로 필요 없지만, 사가의숲식 하루 주기를 들판에 넣을지(그래픽 분위기용). 권장: 넣지 않음(던전 러닝 결).
- **Q3 생성 에셋 커밋**: `assets/generated/` 산출물 커밋 vs 스크립트+씨앗만(빌드 단계 필요, GitHub Pages 는 정적이라 산출물 커밋이 필요할 가능성 높음).
- **Q4 결사(하드코어)와 유품**: 결사는 유품 없음으로 설계했다. 결사에도 "명예 도감" 같은 남는 것을 둘지.
- **Q5 무예 120 축소**: 축복 3택(5.1)이 들어오면 갈래 8 중 서로 겹치는 조합(모양×원소 재탕)을 4갈래로 접어도 선택지가 줄지 않는다. 접을지(데이터만 삭제, 세이브 `skills` 키는 유지) 그대로 둘지.
- **Q6 실기 확인 세션**: Phase 0 의 7.2 목록을 한 번에 확인할 시간(폰 30분 + PC 30분)을 잡을 수 있는지. 못 잡으면 Phase 1 은 진단만으로 진행하고 7.2 는 계속 쌓인다.
