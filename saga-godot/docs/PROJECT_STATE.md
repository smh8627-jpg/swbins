## 현재 작업

- **2026-09-17, PLAN 101-2 DUNGEON ①축복 3택**("사가고돗 이어해") — GO 이식 순서가 끝난 뒤 첫 DUNGEON 후보. 웹 saga-dungeon/PLAN.md §5.1을 옮겼는데, 웹 원안(무예 4칸 장착·서명 무예)이 이 슬라이스 구조(스킬트리 상시 발동, 서명 무예 없음)와 안 맞아 **세 축을 이 슬라이스에 실제로 있는 채널로 재해석**했다(경위는 `dungeon_boons.gd` 파일 헤더에 그대로):
  - **무예 축**: `skillPct`(무예 데미지 전용 배율, `skill_mul()`)에 꽂는 은사 2종(진기·현오) + 즉시 발동형 "비급"(현재 무기 직업에 무예 점수 1 부여, `DungeonSkillState.award_point()` 재사용). **모양별(swing 범위+25% 등) 고유 효과는 범위 밖** — 스킬 스크립트 80여 개를 개별 수정해야 한다(다음 세션).
  - **인물 축**: 기존 14개 중 캐릭터 생존·전투 스탯 11개(fury·wall·haste·dash·pierce·drain·crit·reach·mend·ghost·ward)를 여기 모았다(부대 atkPct/hpPct와 같은 채널).
  - **세계 축**: 기존 경제·탐색 3개(greed·eye·scout) + **원소 시너지 3종 신규**(화+뇌·빙+기·독+전자 — 셋 다 "처치 시 반경 2.35m 확산 피해 14"로 통일, `melee_attack.gd::_check_elem_synergy()`가 `_apply_elemental()`에서 젬 결 조합을 검사). 물리+화 "작열"(콤보 카운터 필요)은 뺐다.
  - `dungeon_run_state.gd::roll_choice()`를 축 다양성(3장이 서로 다른 축)+희귀도 가중(common 60/rare 30/legendary 10)으로 다시 짰고, `reject_choice()`(거절 시 금 30×층) 신규. `test_room.gd`에 카드 라벨(축 아이콘·희귀도 태그)과 4번째 "거절" 버튼 추가.
  - 메타 도감("은사첩")은 안 만든다 — 이 슬라이스의 `boons`가 이미 리셋 없이 유지돼(파일 헤더 원 주석) `boons.keys()`와 항상 같다.
  - 임시 헤드리스 자가진단(`_diag_boons.gd/.tscn`, 커밋 전 삭제)으로 축 다양성 100/100·skill_mul 반영·비급 점수 부여·거절 금액·상한 강제를 확인, 3회 재현. `TestRoom.tscn` 3회 회귀 md5 동일·error/warn 0.
