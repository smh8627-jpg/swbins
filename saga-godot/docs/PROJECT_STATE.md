## 현재 작업

- **2026-09-17, PLAN 101-2 DUNGEON ⑥월드 보스**("이어해") — ⑤난입 다음 후보(마지막), saga-web/saga-dungeon/PLAN.md §5.4를 옮겼다. "부위 3(무기·갑주·머리) 파괴"·"HP 66%/33% 패턴 전환"·"저스트 회피"는 **뺐다**(부위 파괴는 GO ⑥"75초 토벌"이 이미 같은 이유로 뺀 자리 — 105장 열린 질문에 같이 걸어 둠, 패턴 전환은 적 AI에 패턴 자체가 없고, 저스트 회피는 DUNGEON에 범용 회피 입력이 없다) — 남은 표준 H·E("15분 시간표·같은 자리에 등장")만 옮겼다:
  - `dungeon_worldboss_state.gd`(신규, 오토로드 DungeonWorldBossState) — 15분(SLOT_SEC) 벽시계 슬롯마다 경계를 넘으면 보스, 경계 전 3분은 HUD 예고. 체력만 8배(공격력은 그대로 — 웹도 "체력 8배"만 말한다), 층수는 `DungeonSaveState.rooms_cleared.count(true)+1`(player_health.gd::_fall()과 같은 값 재사용). 75초 안에 잡으면 정상 보스 노획+전설 확률×3+부적 1(확정), 못 잡으면 도망(금 30%만). "같은 슬롯 두 번 보상 안 함"은 `last_rewarded_slot` 정수 하나로(웹의 누적 Dictionary 대신 — 슬롯이 벽시계로만 늘어나 그걸로 충분, 무한히 안 커지는 순수 개선).
  - `dungeon_enemy.gd::_init()`에 꼬리 인자 `hp_only_extra_mult`(기본 1.0) 추가 — 기존 `extra_stat_mult`(HP+공격력 둘 다)와 달리 max_hp에만 곱한다("체력만 8배" 그대로 옮기려고 분리).
  - `dungeon_items.gd::roll_tier()`에 `legendary_mult`(기본 1.0) 추가 — 전설(LEGENDARY_TIER=4) 가중치만 곱해 "전설 확률×3"을 실제 굴림에 반영(다른 등급 가중치는 그대로). `roll()`도 그대로 전달.
  - `loot_pickup.gd`에서 금 계산식을 `gold_amount(floor_num, mul)`으로 뽑아(동작 동일) 월드 보스의 "도망 시 30%"가 재사용하게 했고, `spawn_at()`도 `legendary_mult` 꼬리 인자를 그대로 넘기게 확장.
  - `world_boss_director.gd`(TestRoom.tscn 형제 노드, 상시 대기) — 슬롯 경계 감지→방0 고정 자리(정예 스폰과 안 겹치는 위치, 직접 정함)에 스폰→75초 타이머+HP바 HUD→처치/도주 판정. 새 지오메트리·마을/필드 구분 없이 씬을 새로 열 때 "방금 지난 슬롯"은 소급 스폰하지 않는다(실시간 그대로).
  - 임시 헤드리스 자가진단(`_diag_worldboss.gd/.tscn`, 커밋 전 삭제) — 슬롯 수학·hp_only_extra_mult(공격력 안 건드림 확인)·전설 가중 통계(4000회)·gold_amount 회귀 일치·보상 중복 방지·boss_floor_num·저장 왕복·spawn_at 통합까지 16가지(3회 재현, fails=0). `TestRoom.tscn` 3회 회귀 md5 동일(32183836)·error/warn 0, GO·FOREST·STORY·REALM 스모크 오류 0.
