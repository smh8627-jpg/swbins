> **시리즈 전체 인계는 `../SAGA-HANDOFF.md` 다.** 다섯 게임 표·사용자 지시 이력·
> 절대 바꾸면 안 되는 것·밟아 본 함정·다음 할 일이 거기 있다. **새 세션은 그 파일부터.**
> 이 파일은 **사가고 한 판**에 대한 것만 남긴다.

## 지금 상태

**사가고** — 포켓몬GO 를 모방한 판. 걷고(보급), 만난다(등용·포획).
자가진단 **189/189**. 세이브 키는 `deungyong-go/save/<프로필>` (바꾸지 말 것).

```
걷는다  250m 마다 사료·명성, 500m 마다 등용서 (포켓스탑 대신 걸음이 보급)
만난다  인물 등용(설득 3라운드) · 펫 포획(타이밍) → 도감이 쌓인다
자동    🤖 자동 순행 — 목표를 골라 걸어가고, 조우하고, 승급·장비를 챙긴다
```

- 시점 3모드(2D/2.5D/3D) · 등신 3종(2/4/8) · 그림 양식 3종(전통/그림책/만화)
- 온라인 모드의 **사관(AI)** 이 이 판에만 있다 (군략·대화·천기) — `server/` 는 여기 것
- 안드로이드 APK 껍데기(`mobile/`)도 이 판에만 있다 (내용은 v1.7 시절)

**이 판에 없는 것**: 던전·장비(→ `saga-dungeon`) · 문답·경영(→ `saga-realm`).
원작에 없는 축이라 뺐다 — 되살리지 말 것.

## 이 판에서 손볼 때 조심할 것

- `core.hash2` 는 여기만 **옛 식**(0~0.5 만 반환)이다. 다른 넷은 `>>>` 로 고쳤지만,
  이 판의 지형 문턱값이 그 범위에 손으로 맞춰져 있어 그대로 뒀다.
  고치려면 지형·구역 이름을 다시 눈으로 보며 조율해야 한다
- 스프라이트는 코드만 봐서 판정이 안 된다. `_gallery.html`·`_probe.html` 로 crop·확대해서
  **눈으로** 볼 것. 만화풍은 v1.4~v1.5 에서 인물 48·짐승 25 를 전수 다듬었다 —
  결함표(11행)는 커밋 `eb72695` 의 HANDOFF 에 남아 있다. 되돌리면 그대로 재발한다
- `--screenshot` 은 **절대경로** 필수(상대경로면 안 써져서 옛 이미지를 새 결과로 착각한다)
- **폰 화면은 `index.html` 로 본다.** `_demo.html` 은 상단이 별도 마크업이라 폰 폭에서
  도구가 잘리고, `DG_NO_TUNE` 이라 **손잡이를 켜고 끈 비교도 안 된다**(두 장이 똑같이
  나온다). 폰 폭은 헤드리스 창으로 못 만드니 iframe 390px 안쪽에 띄운다
- **3D 값을 고쳤으면 `sw.js` 의 `VERSION` 을 올린다.** 안 올리면 이미 한 번 연 폰이
  앱 캐시에서 옛 파일을 그대로 받아 **아무것도 안 바뀐 것처럼 보인다**

## 이 판에서 이어서 하면 좋은 것

1. **손으로 걸어 보기** — 이동 속도는 2026-08-25 에 34 → 8m/s 로 낮췄다(커밋 `8d8d98d`).
   숫자로는 맞췄지만 조작감은 아직 사람이 보지 않았다
2. ~~자동만으로는 금이 안 모인다~~ — 같은 날 걷기 보급·역참·성채에 금을 넣었다(`8d8d98d`)
3. **APK 다시 굽기** (v1.7 내용) — `cd mobile && npm run apk` (반드시 이 경로)
4. **사관 응답 실청취** — `ANTHROPIC_API_KEY` 주고 8790 으로 군략·천기 한 번씩
5. **폰 실기기 fps** — 2026-08-26 에 폰(공개 주소)에서 열어 보고 **UI 잘림과 세로 화면
   시야각**을 고쳤다(상단 도구 `⋯` 서랍 · `world3d.js` 의 `fovFor`). **아직 커밋 안 했다.**
   다만 고친 것은 배치와 시야각이라 **그리는 양은 그대로다** — 폰에서 버거운지는
   여전히 안 재 봤다. 버거우면 `world3d.density` → 0.5, 그래도 무거우면 `world3d.mesh` → 0.
   자세한 것은 `../SAGA-HANDOFF.md` 의 '이어서 하면 좋은 것' 1번과 '밟아 본 함정'
6. **적도(賊徒) 균형** — 2026-08-26 에 넣었다(`js/rogue.js`). 수치는 눈으로 맞춘 것이지
   손으로 겪어 본 값이 아니다. 어드민의 손잡이 여섯(`rogue.*`)으로 바로 잡을 수 있다.
   특히 **점거 비율 0.22 · 머무는 시간 20분**이 걷는 맛을 정한다 —
   너무 잦으면 보급하러 가는 길이 통째로 싸움이 되고, 너무 드물면 축이 없는 것과 같다.
   정화 값(등급×60 단사)은 **연성과 같은 자원을 다툰다** — 그게 이 축의 선택이다
