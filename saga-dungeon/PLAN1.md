# SAGA DUNGEON — Godot 4.7.2 전환 및 3D 액션 RPG 리빌드 작업지시서

## 0. 최우선 원칙

이 프로젝트는 기존 웹게임을 단순 복사하는 작업이 아니다.

현재:
https://smh8627-jpg.github.io/swbins/saga-dungeon/

현재 게임의 핵심 구조와 콘텐츠 의도는 유지하되,
**Godot 4.7.2 기반의 고품질 3D 모바일 액션 RPG**로 재구축한다.

### 절대 우선순위

1. 토큰 사용량 최소화
2. 기존 프로젝트 분석 후 필요한 부분만 구현
3. Godot 4.7.2 안정 버전 사용
4. 모바일 우선
5. 세로/가로 화면 모두 지원
6. 실제 3D 씬과 3D 캐릭터 사용
7. 시스템을 재사용 가능한 구조로 설계
8. 한 번에 모든 콘텐츠를 만들지 않는다
9. 플레이 가능한 MVP를 먼저 완성한다
10. 이후 콘텐츠를 단계적으로 확장한다

Godot 4.7.2 stable을 기준으로 한다.
Godot 4.8 dev 버전은 사용하지 않는다.


# 30. 토큰 절약을 위한 Claude Code 작업 방식

매 단계마다 다음만 수행한다.

```text
1. 현재 상태 확인
2. 필요한 파일만 읽기
3. 필요한 파일만 수정
4. 실행
5. 오류가 있을 때만 해당 파일 분석
6. 수정
7. 테스트
```

절대 하지 말 것:

```text
전체 프로젝트 다시 읽기
전체 코드 다시 출력
모든 파일 설명
불필요한 리팩토링
이미 정상인 코드 수정
한 번에 모든 시스템 구현
```

# 42. Claude Code 응답 토큰 제한

각 작업 완료 후 보고는 최대한 짧게 한다.

형식:

```text
[완료]
- 변경 파일:
- 구현 내용:
- 테스트:
- 오류:
- 다음 단계:
```

코드 전체를 응답에 출력하지 않는다.

수정한 파일명과 핵심 변경점만 보고한다.
