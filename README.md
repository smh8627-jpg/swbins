# 사가(Saga) — 역사 인물로 노는 다섯 판

브라우저에서 그냥 열리는 웹 게임 다섯입니다. 한국사·삼국지·유럽사 인물 70인과
짐승 41종이 나오고, **그림은 전부 코드가 그립니다**(에셋 파일이 없습니다 — `sprite.js`가
캔버스에 직접 그립니다). 원작이 있는 판은 원작의 축을 옮기되, 원작의 그림은 쓰지 않았습니다.

| 게임 | 폴더 | 무엇 | 원작 |
|---|---|---|---|
| **사가고** | `saga-go` | 실제 지도를 걸으며 인물을 등용하고 짐승을 포획한다 | 포켓몬GO |
| **사가블로** | `saga-dungeon` | 층을 내려가며 장비를 줍는 핵앤슬래시 | 디아블로 |
| **사가의숲** | `saga-forest` | 마을을 가꾸고 주민과 지낸다 | 동물의숲 |
| **사가스토리** | `saga-story` | 옆으로 걷는 액션 | 메이플스토리 |
| **사가국지** | `saga-realm` | 서른 성을 다스리고 꾀고 친다 | 삼국지(코에이) |

## 앞으로 — 다섯 판을 3D 로 옮긴다

다섯 판 모두 **Three.js 기반 3D 로 단계를 나눠 옮기는 계획**이 서 있습니다.
계획은 판마다 제 폴더의 `PLAN.md` 에 있습니다. 이 README 와 각 폴더의 README 는
**지금까지 만든 것**을 적은 문서고, `PLAN.md` 는 **앞으로 갈 곳**을 적은 문서입니다.

| 게임 | 어디로 | 단계 |
|---|---|---|
| **사가고** | 걸어 다니는 3D 역사 탐험 RPG — 인물·짐승·사건을 눈으로 만난다 | PHASE 1~13 |
| **사가블로** | 넓은 필드를 도는 top-down 3D 핵앤슬래시 | Step 1~6 로 잘라서 |
| **사가의숲** | 바이옴이 갈리는 3D 오픈 필드 생활 게임 | Phase 1~15 |
| **사가스토리** | 깊이가 있는 3D 횡스크롤 액션 | Phase 1~6 |
| **사가국지** | 오픈월드 3D 삼국지 — 전략과 액션 전투를 붙인다 | Phase 1~12 |

다섯 계획이 함께 박아 둔 못이 셋입니다.

- **처음부터 새로 만들지 않습니다.** 지금 코드·데이터·UI 를 먼저 읽고, 살릴 것을 정한 뒤
  단계적으로 옮깁니다. 한 번에 다 갈아엎는 방식은 다섯 다 금지했습니다.
- **판정 층과 화면 층을 가른 지금 구조를 그대로 씁니다.** 3D 는 화면 층에 얹는 계층이지
  게임 규칙을 대체하지 않습니다 — 그래야 자가진단(`_test.html`)이 계속 돕니다.
- **원작의 그림·소리·데이터는 여전히 가져오지 않습니다.** 3D 로 가도 같습니다.

큰 작업이라 판마다 폴더에 `CLAUDE.md` 를 두어, 그 폴더를 열면 `PLAN.md` 부터 읽게 했습니다.

## 해 보기

각 폴더에서 로컬 서버를 하나 띄우고 브라우저로 붙습니다.

```
cd saga-go
python -m http.server 8791
# http://127.0.0.1:8791/
```

포트는 관습적으로 사가고 8791 · 사가블로 8792 · 사가의숲 8793 ·
사가스토리 8794 · 사가국지 8795 를 씁니다(폴더마다 `run.bat` 이 있습니다).

**사가고는 위치(GPS)를 씁니다.** `127.0.0.1` 은 보안 컨텍스트라 그냥 되지만,
폰에서 열려면 HTTPS 가 필요합니다(`run-phone.bat` — 인증서는 직접 만들어야 합니다,
`saga-go/server/README.md` 참고). 위치를 못 쓰면 조용히 키보드 이동으로 넘어갑니다.

**파일 하나로 만들기** — `saga-go/build-pc.bat` 을 돌리면 css·js 를 전부 녹인
`dist/사가고.html` 이 나옵니다. 더블클릭으로 열립니다(서버가 필요 없습니다).

## 어떻게 만들어졌나

- **다섯 판은 완전히 별개 프로젝트입니다.** `data.js`·`sprite.js`·`core.js`·`hero.js` 를
  다섯 벌 복사해 나눠 들고 있습니다 — 일부러 그렇게 두었습니다. 한 판의 균형을 고치다
  다섯 판이 같이 흔들리는 것보다 낫다고 봤습니다.
- **판정 층과 화면 층을 갈라 두었습니다.** 실시간 요소(전투·자동 순행·3D)는 화면 없이도
  굴러가는 함수로 판정하고, 그리기는 그 위에 얹습니다. 그래서 헤드리스 브라우저에서
  자가진단이 그대로 돕니다.
- **자가진단** — 각 폴더의 `_test.html` 을 열면 그 자리에서 채점합니다.
  무작위는 씨앗으로 고정돼 있어 몇 번을 돌려도 같은 수가 나옵니다.
  ```
  chrome --headless=new --disable-gpu --virtual-time-budget=45000 \
         --dump-dom http://127.0.0.1:8791/_test.html      # RESULT 189/189
  ```
- **눈으로 보기** — `_demo.html#<장면>` 이 정지 화면을 만들어 줍니다.
  `_admin.html` 은 세이브와 균형 손잡이를 만지는 운영판입니다.

자세한 것은 [`SAGA-HANDOFF.md`](SAGA-HANDOFF.md) 와 각 폴더의 `README.md` 에 있습니다.

## 만든 것에 대해

개인 취미로 만든 것입니다. 원작 게임들의 **구조**를 공부 삼아 옮긴 것이고,
원작의 에셋(그림·소리·데이터)은 하나도 가져오지 않았습니다.
도감에 실린 실존 인물의 열전은 사료를 요약해 직접 썼습니다.
