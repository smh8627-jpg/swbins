# 사가 시리즈 PC 묶음 (saga-pc)

> 시리즈 전체 인계(다섯 게임 표·지시 이력·함정·다음 할 일)는 **`../SAGA-HANDOFF.md`** 다.

집 PC 에서 다섯 판을 통째로 놀 수 있게 굽는 **빌드 도구**다. 게임 코드는 없다.

```
build-all.bat   →  dist/  에 다섯 html + 런처(index.html) + play.bat + 사용법.txt
```

옮기는 법: `dist` 폴더를 통째로 복사(USB·메일·클라우드) → `play.bat` 더블클릭.
서버도 파이썬도 필요 없다.

## 나오는 것

```
dist/
  index.html      런처 — 다섯 판을 고르는 화면 (이름이 ASCII 라 배치가 가리킬 수 있다)
  play.bat        런처를 여는 배치 (내용은 ASCII 만 — 한글 cmd 가 오파싱하지 않게)
  사용법.txt
  사가고.html      ~332KB   포켓몬GO 처럼 걷고 만난다
  사가블로.html    ~375KB   디아블로 처럼 내려간다
  사가의숲.html    ~301KB   동물의숲 처럼 모으고 나눈다
  사가스토리.html  ~308KB   메이플스토리 처럼 뛰고 썬다
  사가국지.html    ~376KB   턴제 삼국지 — 다스리고 꾀고 친다
```

각 판은 그 게임의 `build/build-single.mjs` 가 굽는다(css·js 를 한 파일에 인라인).
여기서는 그 다섯을 차례로 돌리고 모아 런처를 붙이는 일만 한다.

## 한 폴더에 모아도 진행이 안 섞이는 이유

다섯 판은 `file://` 에서 **같은 출처**를 쓴다. 그래도 안전한 건 세이브 키가 게임마다
다르기 때문이다:

```
사가고      deungyong-go/save/<프로필>
사가블로    yeoksa-dungeon/save/<프로필>
사가의숲    yeoksa-village/save/<프로필>
사가스토리  yeoksa-side/save/<프로필>
사가국지    saga-realm/save/<프로필>
```

가입(프로필) 목록도 `<게임>/save/accounts` 로 따로 산다. **그래서 이름도 게임마다 따로다.**
세이브 키를 게임 이름과 맞추려고 바꾸면 지금까지의 진행이 사라진다 — 일부러 옛 이름을 남겼다.

## file:// 에서 되는 것 / 안 되는 것

| | |
|---|---|
| 세이브(localStorage) | ○ 그 PC 의 브라우저에 남는다 |
| 가입·프로필 | ○ |
| 실제 지도 타일 | ○ 인터넷이 되면. 안 되면 그림 지형으로 폴백 |
| 초상화(캔버스 toDataURL) | ○ |
| 서비스 워커 | ✕ 보안 컨텍스트가 아니라 등록되지 않는다 (게임은 그대로 돈다) |
| 실제 위치(GPS) | ✕ 브라우저가 막는다 → 키보드 이동 + 🤖 자동으로 논다 |

## 손볼 때

- 게임을 하나 늘렸으면 `build-all.mjs` 의 `GAMES` 에 한 줄 넣으면 된다
- `.bat` 내용은 **ASCII 만** 쓴다. 한글 cmd(CP949)가 UTF-8 한글을 오파싱한다.
  그래서 런처 이름이 `index.html`(ASCII)이다 — 한글 파일명은 배치가 가리킬 수 없다
- `dist/` 는 커밋하지 않는다 (언제든 다시 만든다)
