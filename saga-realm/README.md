# 사가국지 (saga-realm)

> 시리즈 전체 인계(다섯 게임 표·지시 이력·함정·다음 할 일)는 **`../SAGA-HANDOFF.md`** 다.

**삼국지 — 턴제 전략.** 다스리고, 꾀고, 친다. 판은 셋 — **194년 군웅할거 · 200년 관도 · 208년 적벽**.
2026-08-26 에 사용자 지시 *"삼국지 모방을 할거임"* 으로 판을 통째로 갈아엎었다.
그 전까지 이 판은 **문답 + 경영(상상)** 이었고, 문답은 이제 **학당**이라는 곁가지로 물러났다.

```
run.bat          →  http://127.0.0.1:8795
start_server.bat →  같은 것, 브라우저를 열지 않는다 (허브 워치독용)
_test.html       →  자가진단 95항목
_mobileframe.html→  폰 화면(390px) 확인용 껍데기
_demo.html       →  스크린샷용 장면 (#scen · #pick · #map · #chibi · #grown · #city · #enemy · #war · #camp · #officers · #diplo · #school)
```

## 앞으로 — 3D 로 옮긴다 (`PLAN.md`)

이 폴더의 **`PLAN.md`** 가 앞으로의 방향이다. 이 README 의 나머지는 **지금까지 만든 것**이니,
손대기 전에 둘을 같이 본다.

가는 곳은 **오픈월드형 3D 삼국지 전략 RPG** 다. 지금의 턴제 경영을 버리는 것이 아니라,
그 위에 넓은 월드맵과 액션 전투를 붙인다.

- **반드시 재사용**: 게임 데이터 · 무장 · 성 · 진영 · 외교 · 기록 · 학당 ·
  저장/불러오기 · 기존 UI 로직 · 게임 상태
- **새로 만드는 것**: 3D 렌더링 계층 · 월드 · 카메라 · 캐릭터 · 건물 · 지형 ·
  전투 · 월드 이벤트 · 새 HUD
- 붙일 여덟 축: 탐험 · 랜덤 사건 · 무장 수집 · 장비 · 진형 · 외교 · 역사 분기 · 보스전

**Phase 1~12** 로 잘라 간다 — 엔진 연결 → 카메라 → 플레이어 → 월드 → GLB →
성·도시 → 전투 → 부대 지휘 → 랜덤 사건 → 외교·AI → 경제 → 모바일.

> 경영·문답은 이 판의 것이다. 3D 로 가도 다른 판으로 퍼뜨리지 않는다.

## 놀이 순환

```
달(月)    무장 한 사람이 한 달에 명령 하나. 다 쓰면 ▶ 다음 달
다스린다  개간·상업·기술·치안·축성·징병·훈련·조선·수색·등용   (성마다)
꾄다      외교로 시간을 사고(동맹·화친·조공), 계략으로 깎는다(이간·유언비어·매수·화계)
친다      맞닿은 성으로만 출진. 일기토 → 야전이나 공성 → 함락
원정      한 달에 못 떨어뜨리면 물러나지 않고 **성 밖에 진**. 달마다 한 번씩 더 친다
수전      강끼리 이어진 **물길**은 배로만 건넌다. 성벽이 소용없고 화공이 터진다
기른다    일을 시키면 **경험**이 붙고, 쌓인 **공**으로 **승진**시킨다
곁가지    학당(문답) — 군자금과, 학식이 차면 재야 하나가 드러난다
```

- **금(金)** 은 세력 금고 하나. **군량(糧)** 은 **성마다 따로** — 6·10월에 거둔다.
  코에이가 이 둘을 갈라 둔 데에는 까닭이 있다. 합치면 "군량이 있는 곳으로 싸우러 간다" 는
  판단이 통째로 사라진다
- 승리는 **서른 성 전부**, 패배는 **성을 다 잃는 것**

## 여러 달에 걸치는 원정 (진영)

한 달 안에 성을 못 떨어뜨렸다고 군을 되돌리면 **공성이라는 것이 판에서 사라진다**.
그래서 이 판의 군대는 물러나지 않고 성 밖에 **진(陣)** 을 친다.

```
치중(輜重)  출진할 때 들고 나가는 군량이 곧 진영의 밥이다 — 두 달치
한 달       진영마다 fight() 를 한 번 더 굴린다 (march 와 **같은 함수**다)
사기        달마다 0.94 씩 깎인다. 0.60 아래로 내려가면 군이 지쳐 물러난다
굶주림      치중이 한 달치를 못 채우면 이할이 흩어지고 물러난다
포위 효과   에워싸인 성은 **수확을 못 거두고 인구도 늘지 않는다**
```

- **진중의 굶주림 식은 성과 다르다.** 성은 모자란 만큼을 그대로 병사에서 깎지만
  (`settleMonth`), 진영에 그 식을 쓰면 치중이 떨어지는 그 달에 원정군이 통째로
  사라진다. 성은 물러날 데가 없고 진영은 있다
- **진을 친 성에는 새 군대를 또 못 보낸다**(`canMarch`). 늘리려면 **보급**이다.
  이 단서가 없으면 AI 가 달마다 새 진영을 세워 같은 성 앞에 군대가 쌓인다
- **원정 나간 장수는 성에 없다**(`off.rec(id).camp`). `atCity` 가 빼므로 내정도
  못 하고 수비에도 안 선다. 봉급은 그대로 나간다(`ofForce` 는 센다)
- **AI 는 군량만 댄다**(`rtkAI.trySupply`). 병력 증원까지 AI 에 열어 주면 달마다
  뒷마당을 비워 진영에 몰아주게 되어 균형이 통째로 달라진다. 증원은 사람 손잡이다
- 돌아갈 나라가 사라진 원정군은 그 자리에서 **사로잡힌다** — 그냥 지우면
  판에서 사람이 조용히 사라져 등용할 거리가 준다

120개월을 굴리면 진영이 28~47번 서고, 그중 6~15번이 포위 끝의 함락으로 이어진다
(전체 함락의 이할 남짓). 가장 긴 포위는 서너 달이다.

## 무장 성장 (경험과 승진)

능력치는 `hero.stats(id)` **한 곳**에서 나온다. 성장이 하는 일은 그 함수가 읽는
`save.heroes[id]` 의 `lv`·`rank` 를 올려 주는 것뿐이다 — 성장한 무장이 실제로 더 세게
싸우는 것은 `war.armyPower` 가 같은 `off.stats()` 를 읽기 때문이지,
전투에 따로 붙인 보정이 아니다.

```
경험  내정 명령 +4 · 출진 +12 · 진을 치고 한 달 +8 · 함락 +20 · 일기토 승 +15 · 태수 +2
관직  무관 → 교위 → 중랑장 → 장군 → 대장군 → 도독 (다섯 단)
승진  공(feats) 20+20n 과 금 300+300n. 능력치가 오르고 **충성이 +12**
```

- **`hero.gainExp` 를 쓰지 않는다.** 그쪽은 `save.dex.heroes[id]`(도감에서 뽑은 인물)만
  올려 주는데 이 판에는 뽑기도 도감 획득도 없어 언제나 0 을 준다. 같은 까닭으로
  승급도 `hero.rankUp`(중복 인물 소모)이 아니라 **공**으로 한다 — 삼국지에 중복 인물은 없다
- **AI 도 승진시킨다**(`rtkAI.tryPromote`). 고르는 눈은 하나뿐이다 — 올릴 수 있는 사람
  가운데 **충성이 가장 낮은 사람**. 원작에서 관직이 하는 일이 그것이다.
  이 줄이 없으면 AI 는 120개월에 승진이 한 단도 없고 사람 쪽만 관직 배수를 받는다
  (실제로 그렇게 재 보았다 — 승진 0단이 나왔다)
- 성장은 **일부러 느리다.** 120개월을 굴리면 무장이 평균 Lv.9 (×1.18) 언저리에 선다.
  후하게 주면 늦게 시작한 세력이 영영 못 따라잡는다
- `save.heroes` 는 **세이브 공용 칸**이라 `setup` 이 안 비운다(옛 문답 시절의 레벨이
  그대로 이어진다). 그래서 자가진단의 `fresh()` 는 그 칸을 **함께 비운다** —
  안 비우면 앞 항목이 올려 놓은 레벨이 뒤 항목의 능력치로 흘러 들어간다

## 시나리오 셋

같은 서른 성이지만 **누가 어디를 쥐고 있는지**가 다르다. `data-force.js` 에 표를
하나 더 두면 판이 하나 는다 — 그 밖에 고칠 곳이 없다.

```
194 군웅할거  세력 13. 열세 깃발이 한꺼번에 섰다 (지금까지의 판)
200 관도      세력 8.  하북의 원소와 중원의 조조. 여포도 원술도 이미 없다
208 적벽      세력 6.  조조가 19성을 쥐고 강을 내려온다. 손권과 유비는 동맹으로 시작한다
```

- **어느 표에도 안 적힌 무장은 저절로 재야가 된다**(`rtk.scatterFree`). 200년 표에
  여포·이각·원술을 안 적으면 그들이 재야로 흩어진다 — 죽은 사람을 판에서 지우는 대신
  남겨 두는 것이 이 판의 결이다(지우면 등용할 거리가 그만큼 준다)
- 시나리오의 `pacts` 가 **시작 맹약**을 놓는다. 적벽의 손·유 동맹이 그것이다.
  그것 없이는 적벽이 아니다
- **세이브에 `scen` 이 남는다.** `rtk.state()` 가 그걸 보고 `FD.use()` 를 다시 부른다 —
  이 한 줄이 없으면 208년 판을 열어 두고 새로고침했을 때 194년 표로 읽혀
  세력 이름과 색이 통째로 어긋난다
- `FD.FORCES` 는 **배열을 그대로 갈아 끼운다**(새 배열로 바꾸지 않는다). 다른 파일이
  이미 그 배열을 붙들고 있어서, 참조를 바꾸면 그쪽이 옛 표를 계속 본다
- 200·208년의 유장은 보라(`#9a6b9a`)다. 초록(유비)과 붙어 지도에서 헷갈렸고,
  그 판에는 이각이 없어 그 색이 비어 있다

## 수군 (물길 · 배 · 수전)

**양쪽이 다 강(river)인 길이 물길이다.** 목록을 따로 두지 않았다 — 지형 한 글자만
고치면 물길이 따라 움직인다. 지금 아홉 줄기가 난다.

```
황하  복양↔하비
회수  하비↔수춘 · 수춘↔건업 · 수춘↔시상
한수  양양↔강릉 · 양양↔강하
장강  강릉↔강하 · 강하↔시상(적벽) · 시상↔건업
```

```
배      성마다 따로. 강을 낀 성만 갖는다(처음 60척, 상한 300척)
조선    🛶 새 내정 명령. 강을 낀 성에서만 쓴다
싣기    배 한 척에 100명. 물길 출진은 배에 타는 만큼만 간다
수전    성벽이 곱해지지 않고, 공성추도 없다. 대신 성벽 뒤에 숨지도 못한다
화공    지력이 60을 넘는 사람이 합마다 건다. 터지면 상대 병력 18% · 배 25%
수전 배수  data-force.js 의 `NAVY` 목록 — 이순신 ×1.4 · 주유 ×1.35 · 황개/감녕/채모 ×1.3
```

- **넷째 자질을 만들지 않았다.** `data.js` 의 인물과 모양이 같아야 도감·초상·능력치가
  그대로 돌기 때문이다. "물에서 더 잘 싸운다" 는 **`data-force.js` 의 목록**으로 뒀다 —
  다섯 판이 나눠 가진 `data.js` 를 한 줄도 안 건드리고 적벽이 선다
- **화공은 가늠(`forecast`, dry)에서도 굴린다.** 여기서 빼면 AI 가 보는 승산과 실제가
  어긋난다. 일기토만 뺀 것은 장수가 **진짜로 다치기** 때문이다
- 강을 낀 성에 배를 처음부터 60척 준다. 없이 시작하면 강동이 첫해 내내 아무 데도
  못 가고 판이 그대로 언다
- AI 는 물길 앞에서 배에 맞춰 병력을 줄이고, 배가 모자라면 그 길을 아예 안 고른다.
  **AI 전용 판정이 아니다** — 사람을 막는 `canMarch` 가 AI 도 그대로 막는다

시상(손책)에서 강하(유표)로 2만을 건너 보내면, **주유·황개를 데려갔을 때와
주태만 데려갔을 때의 손실이 두 배 넘게 벌어진다.**

## 무장 124 — 명부를 어떻게 늘렸나

```
data.js        인물 70 (삼국지 22 · 한국사 26 · 유럽사 22)  ← 다섯 판이 **바이트까지 같은 복사본**
data-force.js  무장 54 (삼국지 군주 13과 부하들)            ← 이 판만의 것
```

`data.js` 는 손대지 않는다. **부팅 때 `officer.js` 가 54인을 `DG.data.heroes` 에 얹는다** —
`data.find` 가 배열을 그때그때 훑는 구조라 얹기만 하면 `hero.stats`·`sprite.portrait`·도감이
그대로 돈다. 다섯 판을 맞출 일이 생기지 않는다.

**삼국지 사람이 아닌 인물 48(한국사·유럽사)은 재야(在野)** 다. 성에 흩어져 있고,
**수색해야 보이고 등용해야 온다.** 이순신이 손권 밑에서 수군을 맡는 판이다.
재야는 이름 해시로 **결정적으로** 흩는다 — 무작위로 흩으면 진단이 실행마다 다른 성을 짚는다.

## 폰에서

**절반은 처음부터 돼 있었다** — manifest·서비스워커·safe-area·780px 미디어쿼리.
폰 폭(390px)에서 실제로 열어 보고 **막히는 것만** 골라 고쳤다.

```
_mobileframe.html          폰 화면(390px)을 헤드리스에서 보는 껍데기
_mobileframe.html#probe    상단·독·지도·다음달이 화면 안에 있는지 재서 PROBE OK
_mobileframe.html#camp     그 장면을 폰 폭으로 (…#city #officers #ask #scen …)
_mobileframe.html?fresh    가입 화면부터
```

헤드리스 크롬은 창 폭을 **500px 아래로 안 내려 준다**. 그래서 iframe 안쪽에
진짜 390px 뷰포트를 만든다(사가의숲·사가블로 것과 같은 꼴이다).

고친 것은 넷이다.

1. **`prompt()` 를 걷어냈다.** 출진·보급·증원·병력 보내기 넷이 `prompt` 로 숫자를
   받고 있었다. 폰에서 `prompt` 는 숫자 키패드가 아니라 글자판을 띄우고,
   홈 화면에 담아 띄운 앱(standalone)에서는 아예 안 뜨는 기기가 있다.
   **미는 막대와 ¼·½·⅘·전부** 를 가진 카드로 바꿨다(`ui.askNumber`)
2. **지도의 성이 손가락에 안 닿았다.** 성 점은 화면에서 8px 남짓이다.
   보이지 않는 큰 원(`.rhit`, r=4.2)을 하나 깔았다 — 그림은 그대로, 손만 커진다
3. **상단이 두 줄로 접히는데 지도가 그대로였다.** 780px 아래에서 `#realm` 을
   148px 로 내렸다. 안 내리면 북쪽 성들이 상단 유리판 밑으로 들어가 못 눌린다.
   `.p-sub` 는 한 줄로 — "수입 388/월" 의 '월' 이 떨어져 나갔다
4. **`touch-action: manipulation`** — iOS 사파리는 `user-scalable=no` 를 무시해서
   더블탭 줌이 성 누르기를 방해한다

폰에서 여는 길은 둘이다. **GitHub Pages(https)가 확실하다** — 서비스워커와
홈 화면 추가가 거기서만 붙는다. 같은 와이파이에서 `run.bat`(0.0.0.0 바인딩)으로
`:8795` 를 열어도 놀 수는 있지만 http 라 캐시가 안 붙는다.
**이 판은 위치 API 를 쓰지 않아 HTTPS 가 필수는 아니다** — 그래서 `run-phone.bat` 이 없다.
