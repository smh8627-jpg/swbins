# SAGA-REALM Unity 3D 전환 및 전면 리뉴얼 작업 지시서

## 0. 최우선 규칙 — Claude Code 토큰 절약

이 프로젝트는 Claude Code의 토큰 사용량을 최대한 절약한다.

### 절대 규칙

1. 작업 전에 전체 프로젝트를 무작정 읽지 않는다.
2. 필요한 파일만 먼저 탐색한다.
3. 동일한 파일을 반복해서 읽지 않는다.
4. 이미 확인한 코드는 다시 출력하거나 설명하지 않는다.
5. 긴 코드를 답변에 그대로 출력하지 않는다.
6. 변경이 필요한 부분만 수정한다.
7. 기존 코드를 무조건 삭제하고 재작성하지 않는다.
8. 작은 변경은 작은 패치로 처리한다.
9. 작업 완료 후 전체 파일을 다시 출력하지 않는다.
10. 사용자가 요청하지 않은 기능은 임의로 추가하지 않는다.
11. Unity Editor에서 자동 생성 가능한 파일은 직접 대량 작성하지 않는다.
12. 에셋을 사용할 경우 동일 에셋을 여러 곳에서 재사용한다.
13. 새로운 시스템을 만들기 전에 기존 시스템 재사용 가능성을 먼저 확인한다.
14. 한 번에 모든 기능을 구현하지 않는다.
15. 항상 다음 단계로 넘어가기 전에 현재 단계의 컴파일 오류를 확인한다.

### 작업 방식

반드시 다음 순서로 작업한다.

```
탐색
↓
현재 구조 요약
↓
Unity 프로젝트 생성
↓
핵심 시스템 이전
↓
3D 그래픽 구축
↓
게임플레이 구축
↓
UI/모바일 입력
↓
콘텐츠 확장
↓
최적화
↓
빌드 테스트
```

각 단계에서 필요한 파일만 확인한다.

# 23. 성능 최우선

모바일 게임이므로 그래픽만 높이고 성능을 희생하지 않는다.

목표:

- 안정적인 FPS
- 낮은 메모리 사용
- 낮은 배터리 사용
- 빠른 초기 로딩
- 적절한 draw call
- 적절한 texture memory

Unity Profiler를 사용해 실제 병목을 확인하면서 최적화한다.

Unity 역시 모바일 게임은 실제 기기에서 프로파일링하면서 병목을 찾는 것을 권장한다.

# 33. 중요 — 한 번에 완성하려 하지 않는다

Claude Code는 전체 게임을 한 번에 구현하지 않는다.

첫 번째 목표는:

"실행 가능한 Unity 3D 프로토타입"

이다.

최초 결과:

- 3D 필드
- 플레이어
- 카메라
- 이동
- 적 1종
- 기본 공격
- HP
- 간단한 UI

까지만 우선 완성한다.

정상 실행을 확인한 뒤 다음 기능으로 넘어간다.

---

# 34. 에셋 사용 원칙

에셋을 사용할 경우:

- 모바일 최적화 여부 확인
- 라이선스 확인
- 동일 에셋 반복 사용
- Atlas 활용
- Texture 크기 관리
- LOD 활용
- 불필요한 고해상도 리소스 사용 금지

에셋을 많이 넣는 것이 품질이 아니라,

"일관된 아트 스타일 + 적절한 배치 + 조명 + VFX"

를 통해 품질을 높인다.

---

# 35. 절대 하지 말 것

다음 행동은 금지한다.

- 전체 프로젝트 무차별 분석
- 기존 파일 전체 출력
- 동일 파일 반복 읽기
- 불필요한 라이브러리 추가
- 불필요한 패키지 추가
- 모든 기능을 한 번에 구현
- 임시 코드 남발
- 하드코딩 남발
- 모바일 성능 무시
- Primitive만으로 최종 그래픽 구성
- UI만 먼저 화려하게 만드는 작업
- 실제 게임플레이 없이 장식만 만드는 작업

---

# 36. 작업 보고 방식

각 작업 완료 후 다음 형식으로 매우 짧게 보고한다.

```
[완료]
- 작업:
- 변경 파일:
- 테스트:
- 오류:
- 다음 단계:
```

변경하지 않은 파일은 보고하지 않는다.

긴 설명을 하지 않는다.

---

# 37. 오류 처리

컴파일 오류가 발생하면 새로운 기능 추가를 중단한다.

순서:

오류 확인
↓
원인 파일 확인
↓
최소 수정
↓
컴파일 확인
↓
다음 작업

---

# 38. 최종 목표

최종적으로 SAGA-REALM은 다음 느낌을 목표로 한다.

"삼국지 세계를 직접 돌아다니며 장수를 모으고 성장시키는 모바일 3D 액션 RPG"

단순한 웹 게임을 Unity로 옮긴 느낌이 아니라,

기존 프로젝트를 기반으로 새롭게 제작한 모바일 게임처럼 보여야 한다.

---

# 39. 첫 번째 실행 명령

지금부터 바로 전체 게임을 만들지 않는다.

먼저 다음만 수행한다.

1. 현재 SAGA-REALM 구조를 최소한으로 분석
2. Unity 프로젝트 구조 설계
3. 필요한 패키지 목록 확인
4. 기존 기능 중 Unity로 이전할 핵심 기능 선정
5. Phase 1 구현 계획 작성
6. Unity 프로젝트 생성
7. 기본 3D World Scene 생성
8. 플레이어 이동 구현
9. 카메라 구현
10. 실행 테스트

이 단계가 정상적으로 완료되면 다음 Phase로 진행한다.

# 41. Claude Code 최종 지시

지금 바로 구현을 시작한다.

단,

"전체 프로젝트를 분석하고 모든 것을 한번에 작성"

하지 않는다.

필요한 파일만 확인하고 최소한의 코드로 첫 번째 실행 가능한 Unity 3D 프로토타입부터 만든다.

각 단계마다 컴파일 및 실행 가능 여부를 확인한다.

토큰 사용량을 항상 최소화한다.

이미 확인한 내용은 반복해서 읽거나 설명하지 않는다.

현재 단계에 필요한 작업만 수행한다.

최종적으로 기존 SAGA-REALM보다 훨씬 높은 수준의 3D 모바일 RPG를 목표로 한다.
