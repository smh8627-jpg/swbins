# 캐릭터 에셋 실태 — "전부 에셋인가, 모두 다른가" (2026-09-25 조사)

사용자: "캐릭터 전부 에셋이 맞아? 모두 달라야 해. 색깔만 다른 게 아니라." — 웹 다섯 판을 판별로 읽기 전용 조사했다.
**상태 파일이다(덮어쓴다).** 고친 뒤엔 숫자를 새로 잰다. 줄 번호는 조사한 날 기준.

## 한 줄 결론

**거의 모든 캐릭터가 실제 에셋이지만(코드 도형은 로딩 중·실패 때뿐), 사람은 거의 다 "몸 4벌 + 색 바꾸기"다.**

- 원인 하나: 다섯 판 `asset3d.js` 의 `world3d.animeAvatar` 기본값이 **1**(켜짐)이다. 그러면 사람은 전부
  `HERO_RECIPES_ANIME` — VRoid 몸 **4벌**(`avatar_sample_a/b/c`·`avatar_custom_01`) 중 id 해시로 하나를 입는다.
  (몇몇 판 주석은 "기본 꺼짐"이라 적혀 있는데 낡은 주석이다.)
- `vroid-variant.js` 는 **색만** 바꾼다 — `_HAIR`·`_CLOTH`·`EyeIris` 재질에 12색 × 3. 얼굴·머리 모양·옷 모양·체형은 그대로.
- 그래서 디스크에 있는 다른 사람 몸(사가블로 159벌·QRPG 6·MPFB 20 등)은 기본 플레이에서 **안 쓰인다**.
- 초상도 이 4벌로 구웠다 → 파일은 사람마다 있어도 얼굴은 사실상 넷.
