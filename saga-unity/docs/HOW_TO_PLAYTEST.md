# saga-unity 실기 테스트 방법

이 문서는 **사람이 직접 Unity 에디터를 켜서 손으로 조작해 보는 법**이다.
세션들이 해 온 "Saga/Playtest ... (Headless)" 메뉴 검증은 컴파일 오류·
씬 로드·수치 계산이 안 깨졌는지만 확인하는 것이고, **화면이 실제로 어떻게
보이는지·조작 손맛이 어떤지는 여전히 사람이 직접 봐야 한다.** 그게 이
문서가 다루는 "실기 테스트"다(같은 목적의 `saga-godot/docs/
HOW_TO_PLAYTEST.md`와 짝을 이룬다 — 두 프로젝트는 병행 트랙이라 별개
문서다).

---

## 1. Unity 에디터 준비

이 PC에는 이미 **Unity 6000.3.23f1**이 Unity Hub 경유로 설치돼 있다
(`C:\Program Files\Unity\Hub\Editor\6000.3.23f1`). 다른 PC에서 이
문서를 보고 있다면 버전이 다르거나 없을 수 있다 — 없으면 [Unity
Hub](https://unity.com/download)를 먼저 설치하고, Hub의 **Installs**
탭에서 이 프로젝트와 같은 버전(6000.3.23f1, 없으면 6000.3.x 최신)을
받는다.

설치 확인만 하고 싶으면:
```bash
find "/c/Program Files/Unity/Hub/Editor" -maxdepth 1
```

---

## 2. 프로젝트 열기

1. Unity Hub를 실행한다
2. **Projects** 탭 → **Add** (또는 **Open**) 버튼 클릭
3. `C:\swbins\saga-unity` 폴더를 선택 (프로젝트 폴더 자체를 고른다,
   `.unity` 파일이 아니다)
4. 목록에 "saga-unity"가 추가되면 클릭해서 연다
5. 처음 열 때는 스크립트 컴파일·에셋 임포트로 시간이 좀 걸린다 —
   에디터 우하단 진행바가 끝날 때까지 기다린다

---

## 3. 씬 열고 실행하기

에디터 좌하단 **Project** 창에서 `Assets/Scenes/` 안의 `.unity` 파일을
더블클릭하면 그 씬이 **Scene** 뷰에 열린다. 그 상태에서 위쪽 가운데
**▶ Play** 버튼(또는 **Ctrl+P**)을 누르면 **Game** 뷰에서 실제로
조작해 볼 수 있다. 다시 누르면(또는 Ctrl+P) 정지한다.

**씬이 비어 보이거나 코드 변경분이 안 보이면** — 이 씬들은 절차적으로
지어진 것이라(코드가 지형·건물·NPC를 배치), 에디터 메뉴 **Saga →
Build <씬이름> Scene**(아래 표의 "재빌드 메뉴" 칸)을 한 번 실행해
다시 지은 뒤 **Ctrl+S로 저장**하고 Play한다. 평소엔 이미 지어진 채로
커밋돼 있어 그냥 열고 Play만 해도 된다.

---

## 4. 게임별로 열 씬

| 게임 | 열 씬 (`Assets/Scenes/`) | 재빌드 메뉴 (Saga →) |
|---|---|---|
| 사가고 (GO) | `TestVillage.unity` | Build TestVillage Scene |
| 사가블로 (DUNGEON) | `TestDungeon.unity` | Build TestDungeon Scene |
| 사가의숲 (FOREST) | `TestVillageForest.unity` | Build TestVillageForest Scene |
| 사가스토리 (STORY) | `TestField.unity` | Build TestField Scene |
| 사가국지 (REALM) | `TestCity.unity` | Build TestCity Scene |

(`SampleScene.unity`는 Unity 템플릿 기본 씬 — 이 프로젝트와 무관, 안 연다)

**Saga 메뉴의 나머지 항목("Playtest ... (Headless)", "Simulate ...")은
사람이 쓰는 게 아니다** — 세션이 코드 검증용으로 배치 모드에서 돌리는
자동 확인이다. 에디터에서 직접 눌러도 동작은 하지만(창 없이 로그만
찍고 끝난다), 실기 테스트에는 위 "Build ... Scene" 항목만 쓴다.

## 5. 공통 조작 (다섯 판 대부분 같다)

| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 (`Move` 액션) |
| Shift | 달리기 (`Sprint` 액션) |

사가고·사가블로·사가의숲 셋은 이 표대로 CharacterController로 걷는다.
사가스토리는 가로 이동만(아래 6절), 사가국지는 걸어 다니는 캐릭터가
없어(경영형) 이 표가 적용되지 않는다(6절 참고).

## 6. 게임별 조작

### 사가고 (GO)
이동뿐, 전투·조우는 전부 **화면 버튼 클릭**이다(키보드 단축키 없음):
NPC에게 다가가면 자동으로 말을 걸고, 도적을 만나면 **맞선다 / 값을
치른다 / 달아난다** 버튼이 뜨고, 맞서면 **속공 / 필살 / 회피 / 물러난다**
버튼으로 싸운다(필살은 기(氣) 게이지가 찼을 때만 눌린다). 화면 왼쪽
위엔 디버그 빌드에서만 보이는 오버레이(렌더러·FPS·레벨·사명·좌표)도
있다. 화면 오른쪽 위 **"저장" 버튼 글자는 2026-09-15부터 플레이 중
언어 전환에도 실시간으로 반응한다**(이전엔 씬 빌드 시점 언어로 굳어
있었다). 그 바로 아래 **"설정"**(효과음·진동·UI 크기·그래픽 품질,
2026-09-14 추가 / 언어(ko/en), 2026-09-14 추가 / BGM On-Off, 2026-09-15
추가)도 있다.

### 사가블로 (DUNGEON)
| 키 | 동작 |
|---|---|
| Space | 평타 공격 |
| Left Alt | 강공격(쿨다운 1.3초, 피해 2.6배) |
| E | 회전베기(2026-09-14 추가 — 반경 2.8m 안 전체 타격, 대상당 피해는 평타의 0.7배, 쿨다운 3.5초) |
| Left Ctrl | 회피(구르기, 무적 프레임) |
| M | 지역 지도 패널 토글(나침반형 5칸 — 텔레포트 없음, 보기만) |

모바일용 화면 버튼(공격·강공격·회전베기·회피)도 같은 함수를 부른다 —
마우스로도 된다. **이 버튼들(+저장 버튼)의 글자는 2026-09-15부터
플레이 중 언어 전환에도 실시간으로 반응한다**(이전엔 씬 빌드 시점
언어로 굳어 있었다). 화면 왼쪽 위엔 디버그 빌드에서만 보이는 오버레이
(렌더러·FPS·레벨·층·적 수·사명·좌표)도 있다. 화면 오른쪽 위 미니맵
아래 **"설정"**(효과음·진동·UI 크기·그래픽 품질, 2026-09-14 추가 /
언어(ko/en), 2026-09-14 추가 / BGM On-Off, 2026-09-15 추가)도 있다.

### 사가의숲 (FOREST)
이동은 키보드/조이스틱, 나머지는 전부 **다가가기만 하면 자동으로
반응**한다(누르는 키가 따로 없다):
- 숲지기(주민)에게 다가가면 대사 토스트.
- 과일나무에 다가가면 자동 채집(쿨다운 2초, 무제한 반복 가능).
- 집 문 앞에 다가가면 실내로, 반대편에 다가가면 다시 밖으로 전환.
- 집 안 가구 자리·집 밖 도배전(벽지/장판)에 다가가면 자동으로 룰렛을
  돌려 못 가진 것 중 하나를 산다(전부 가진 뒤엔 이미 가진 것끼리
  무료로 갈아입는 룰렛으로 바뀐다).
- 여덟 창조물 중 **포자괴물**만 적대 — 대치하면 "밀어내기!" 버튼을
  연타해 게이지를 비우는 미니게임이 뜬다(2026-09-14 추가, 실패해도
  처벌 없음 — 이기든 늦게 이기든 창조물은 결국 물러난다).

화면 왼쪽 위엔 디버그 빌드에서만 보이는 오버레이(렌더러·FPS·좌표)도
있다 — FOREST엔 전투·성장·경제가 없어 레벨·사명 줄은 없다. 화면
오른쪽 위 **"저장" 버튼 글자는 2026-09-15부터 플레이 중 언어 전환에도
실시간으로 반응한다**(이전엔 씬 빌드 시점 언어로 굳어 있었다). 그
바로 아래 **"설정"**(효과음·진동·UI 크기·그래픽 품질, 2026-09-14
추가 / 언어(ko/en), 2026-09-14 추가 / BGM On-Off, 2026-09-15 추가)도
있다.

모바일용 화면 버튼(좌/우/오르기/내리기/점프/공격/횡소/기탄/기합, 그 위
교대 셋, 그 위 무예 칸 넷, 맨 위 "무예")도 같이 배선돼 있다. **2026-09-23
전까지는 모바일 버튼이 전부 먹통이었다**(씬 저장 때 리스너가 안 남던 버그 —
같은 날 다섯 판 모두 고침). **점프·공격·기합·기탄·횡소 버튼 글자는 2026-09-15부터
플레이 중 언어 전환에도 실시간으로 반응한다**(이전엔 씬 빌드 시점
언어로 굳어 있었다). **전직관(NPC, 척후병보다 5m 더 멀리)에게 다가가면
Lv.10부터 전직 선택 팝업이 뜬다**(2026-09-15 추가, 무사/궁수/협객/
방사 중 하나, 1회뿐 — 공격력(·방사만 기력)이 오르고, **2026-09-23부터 직업
무예 1차(무사·방사 5개, 궁수·협객 6개)를 무예 점수로 익힐 수 있다** — 전직
직후와 전직관을 다시 찾을 때 무예 패널이 뜬다). 치유 무예는 이 판 플레이어가
안 맞아서 빠져 있다. **2차 전직(2026-09-23)**: Lv.15 + 1차 무예 하나를 5 이상
익힌 뒤 전직관에게 가면 "장군/신궁/자객/도사로 오르겠습니까?"가 뜬다(오른다/나중에).
오르면 2차 무예(같은 유파 1차 무예 5가 먼저)를 찍을 수 있고, 무예 칸에 **같은 유파가
둘 놓이면 세트**가 켜져(무예 패널 줄 앞 "[정(正)·2세트]") 피해·범위·강화 지속·발수·돌진
재사용 대기 중 하나가 좋아진다. 비경 적은 이제 내 레벨만큼 경험치를 준다(Lv.10→15 비경 약 4판).

들판의 척후병(NPC)에게 다가가면 자동으로 말을 건다(키 조작 불필요,
계속 마주칠수록 인사말이 데워진다). **두목을 처치한 직후** 첫 대화는
평소 대사 대신 "함께 축배를 든다 / 간단히 치하만 받는다" 선택 팝업이
뜬다(2026-09-14 추가, 장식적 분기 — 어느 쪽을 골라도 게임 상태는 안
바뀌고 이후 어투만 갈린다). 화면 왼쪽 위엔 디버그 빌드에서만 보이는
오버레이(렌더러·FPS·사명·좌표)도 있다. 화면 오른쪽 위 "저장" 버튼
바로 아래 **"설정"**(효과음·진동·UI 크기·그래픽 품질, 2026-09-14
추가 / 언어(ko/en), 2026-09-14 추가 / BGM On-Off, 2026-09-15 추가)도
있다.

## 7. 세이브 파일 위치

다섯 판 모두 `Application.persistentDataPath`(이 PC·이 프로젝트 설정
기준 `%USERPROFILE%\AppData\LocalLow\DefaultCompany\SAGA\`)에 판마다
다른 JSON 파일로 저장한다 — 이름이 겹치지 않으니 한 폴더에 다 있어도
안전하다:

| 게임 | 파일명 |
|---|---|
| 사가고 | `save.json` |
| 사가블로 | `save_dungeon.json` |
| 사가의숲 | `save_forest.json` |
| 사가스토리 | `save_story.json` |
| 사가국지 | `save_realm.json` |

메모장으로 열어 손으로 고칠 수 있다 — 정확한 필드 이름·타입은 각 판의
`Data/*SaveState.cs`의 `SaveData` 클래스를 보고 맞춘다(saga-godot의
JSON 세이브와 달리 필드가 아직 자주 바뀌는 중이라 이 문서에 예시를
박아 두지 않는다 — 최신 필드는 코드가 정본).

## 8. 확인 끝나면

- Play 모드를 정지하고, 에디터도 필요 없으면 닫는다(작업관리자에
  `Unity.exe`가 남아 있으면 `taskkill //F //IM Unity.exe`로 정리 —
  다른 세션이 saga-godot용으로 띄운 `Godot_v*.exe`까지 잡지 않도록
  정확한 이름만 쓴다)
- 무엇을 봤는지(어느 씬, 어떤 조작, 뭐가 이상했는지) 다음 세션에게
  한 줄이라도 남겨 준다 — `docs/PROJECT_STATE.md` 맨 아래(최신 항목)에
  적어 두면 "saga-unity 이어해"만으로 다음 세션이 이어서 봐줄 수 있다
